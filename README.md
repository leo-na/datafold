
# Datafold   
Mini application React consommant la PokéAPI

Datafold est une mini application front-end développée avec **React** et **Vite**, visant à démontrer la consommation d’une API externe, la gestion d’état côté client et une interface utilisateur simple mais complète.

Le projet met en œuvre une **Pokédex interactive** avec pagination, recherche, favoris persistants et affichage détaillé des statistiques des Pokémon.

---

##  Fonctionnalités

-  Liste paginée de Pokémon (20 par page)
-  Recherche d’un Pokémon par nom
-  Suggestions rapides (ex : pikachu, ditto, gengar)
-  Gestion des favoris (persistés via LocalStorage)
-  Affichage détaillé des statistiques
-  Chargement asynchrone avec états de loading et gestion des erreurs

---

##  Technologies utilisées

- **React** (hooks : `useState`, `useEffect`, `useMemo`)
- **Vite** (environnement de développement)
- **Axios** (requêtes HTTP)
- **PokéAPI** – https://pokeapi.co/
- **LocalStorage** (persistances des favoris)
- **CSS** (layout simple et responsive)
